# @tec-triad/iconforge-svg

Framework-agnostic raw SVG vector icon assets for IconForge in 6 visual styles.

## Overview

Contains pre-rendered, optimized SVG files categorized by domain and visual style:
- `outline/`
- `filled/`
- `duotone/`
- `multicolor/`
- `gradient/`
- `rounded/`

All SVG vectors use a standard `24x24` viewBox with rounded line caps and joins.

## Installation

```bash
npm install @tec-triad/iconforge-svg
```

## Usage

```html
<img src="node_modules/@tec-triad/iconforge-svg/svg/outline/general-ui/search.svg" alt="Search" width="24" height="24" />
```
