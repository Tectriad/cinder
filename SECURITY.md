## Reporting a Vulnerability

The Cinder UI and IconForge team takes the security of our software seriously. If you believe you have discovered a vulnerability, please report it responsibly.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please send an email to our security team:

- **Email**: `security@techtriad.info`

Include as much of the following information as possible:
- Type of vulnerability (e.g. XSS, prototype pollution, dependency vulnerability)
- Package and version affected
- Step-by-step reproduction instructions or a minimal proof of concept
- Potential impact and recommended remediation

---

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours of receiving the report.
- **Assessment and Confirmation**: Within 5 business days.
- **Fix and Disclosure**: We aim to release a patched version within 14 days of confirming the vulnerability, followed by an advisory.

Thank you for helping keep Cinder UI, IconForge, and our community safe.
